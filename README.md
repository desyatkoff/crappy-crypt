# Crappy Crypt

## Description

Totally unsafe and unuseful CLI encrypt/decrypt thing, it's just a first program I decided to build in Rust (better than "Hello World!" though)

## Installation

1. **Clone the Repository**
    ```Shell
    $ git clone https://github.com/desyatkoff/crappy-crypt.git
    ```
2. **Go to the Repository Directory**
    ```Shell
    $ cd crappy-crypt/
    ```
3. **Compile the Rust Project**
    ```Shell
    $ cargo build --release
    ```
